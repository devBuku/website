rtcamern

A real-time chat app, hand-coded from scratch. Two people sign in, message each other instantly, see who is online and send photos and videos.

Express 5 and Socket.IO server, MongoDB, Clerk sign-in kept in sync through webhooks, file uploads with Multer stored on ImageKit. Ships as a single Docker image. Every part is explained in a docs folder.

stack: React 19, Vite, TypeScript, Tailwind CSS, Express 5, Socket.IO, MongoDB, Clerk, Docker

College ERP system

One web app for a college's admissions, exams, attendance, fees and library.

A final-year project by a team of five. I wrote all the backend APIs for the library module (catalogue, issue and return, overdue tracking, reports) and the exams and results module (scheduling, marks entry, grades, transcripts), plus the dashboard reporting endpoints. Login uses JWT with role-based access for students, faculty and admins. It was demoed on a VPS, and my college is currently evaluating it for production use. The demo server has since been taken down to save hosting costs.

stack: PostgreSQL, Express, React, Node.js, Redis, Prisma, Docker, Nginx, TypeScript, Tailwind CSS, Zustand, TanStack Query, Zod, JWT, Python (data ingestor)

private repo · walkthrough on request

Swarlipi

Turns a video into another language. Speech is transcribed, translated and re-voiced, and the new audio is stretched to match the original timing.

A pipeline with Whisper, Google Translate and gTTS, with pydub and moviepy to keep the audio and video in sync. National finalist at Smart India Hackathon 2023 (CGC Landran, Punjab, 19-20 December 2023).

stack: Python, Flask, HTML templates, OpenAI Whisper, Google Translate API, gTTS, pydub, moviepy

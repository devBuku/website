## Data

- Collection of raw bytes
- By itself, data has no specific purpose or meaning.
- Data is the raw material that is processed into information for decision-making.

### Types of Data

- Quantitative
  - Numerical data (e.g. weight, volume, cost)
- Qualitative
  - Descriptive, non-numerical data (e.g. name, gender, hair color)

> Data is the new oil.

---

## Information

- Processed, organized, and structured data
- Data + processing/interpretation → Meaning → Information

---

## Database

- An electronic system where data is stored so it can be:
  - Accessed easily
  - Managed
  - Updated

---

## Database Management System (DBMS)

### What

- Software used to manage databases.
- Consists of:
  - A collection of interrelated data
  - A set of programs to access and manage that data

---

## Why DBMS Instead of a File System?

A traditional file system can implement all the features, but doing so is complex and repetitive. A DBMS provides them out of the box.

### Problems with File Systems

- Data redundancy and inconsistency
- Difficulty accessing data (especially with constraints and complex queries)
- Integrity problems
- Atomicity problems
  - Example: After debiting one account, the corresponding credit must also happen.
  - There should be no partial transaction; either the entire transaction succeeds or it is rolled back.
- Security problems
